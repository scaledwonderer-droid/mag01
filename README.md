# Housing Magazine Generator

6枚のハウジング用スクリーンショットと文章を組み合わせ、アンティーク調の雑誌見開き画像を作成できるブラウザ完結型エディターです。

## 使い方

1. 「画像」タブから6枚のスクリーンショットを選びます。
2. プレビュー上で画像をドラッグし、ホイールまたはスライダーで拡大率を調整します。
3. 「文章」タブで店名、コピー、各写真の記事を編集します。
4. 紙面上の文字枠は滑らかにドラッグ移動でき、右下の青いつまみで枠サイズも変更できます。Ctrl（MacはCommand）を押しながら動かすとグリッドへ吸着します。
5. 必要なら自由テキスト・自由画像を追加します。
6. 「詳細編集モード」で写真枠を含む全要素を調整し、PNGまたはJPEGで保存します。

作業内容はブラウザの `localStorage` に自動保存されます。「プロジェクト保存」で画像を含むJSONをダウンロードすると、別のブラウザでも「読込」から復元できます。

## GitHub Pagesで公開

`dist/` フォルダーの中身を公開対象にしてください。サーバー処理やビルドは不要です。GitHub Actionsを使う場合は、Pagesの成果物として `dist/` をアップロードします。

## ローカル起動

任意の静的HTTPサーバーで `dist/` を公開してください。例：`python -m http.server 8000 -d dist`

## プライバシー

アップロードした画像、入力した文章、プロジェクトデータは外部サーバーへ送信されません。画像処理・保存・書き出しはすべて利用者のブラウザ内で行われます。
